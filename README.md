I build reproducible econometric analyses, leakage-safe forecasting pipelines, and interactive analytical web applications in **R** and **Python**. My work combines statistical rigor (causal inference, time-series validation, zero-inflated modeling, and spatial/unsupervised segmentation) with software engineering standards (automated testing with `testthat` and `pytest`, locked environments via `renv`, CI/CD via GitHub Actions, and bilingual publication with Quarto and Shiny).

## Featured Projects / Proyectos Destacados

### Interactive Web Applications (Shiny for Python)

- **[Public Procurement Risk Observatory — SECOP II (`eda-colombia-shiny`)](https://github.com/MPalma21/eda-colombia-shiny)**  
  Analytical web application and territorial early-warning semaphore system for Colombian public procurement data (`datos.gov.co`). Engineered with a modular architecture, custom statistical components, and a 42-test `pytest` suite.
- **[Colombian Hotel Market Segmentation (`segmentacion-hotelera-colombia`)](https://github.com/MPalma21/segmentacion-hotelera-colombia)**  
  Multidimensional unsupervised clustering ($K$-Means) integrating tourism supply, air connectivity, and official geography into an interactive geospatial dashboard built with Shiny for Python, `ipyleaflet`, and Plotly.
